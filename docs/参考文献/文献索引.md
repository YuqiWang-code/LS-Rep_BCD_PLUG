## 0. 总览：文献 → GRAFT 组件映射

GRAFT-PLUG 的四个组件分别由下列文献支撑：

| GRAFT 组件 | 支撑文献 |
|---|---|
| **BSEE**（双时相对称证据编码器） | T-CoRe（temporal latent teacher）、COSMOS（global/local view） |
| **CGR**（跨阶段全局推理器） | DEO（global+patch 多层教师）、ATAS（所有 representation levels） |
| **LSP + 自蒸馏**（局部 stage 探针） | PH-Reg（dense teacher/student）、LAL（特权辅助分支）、RD-Net（单分支推理）、MAN（local auxiliary） |
| **KGR**（知识缺口梯度路由器） | SDPGO（gradient-critical feature）、ADMD（discrepancy-masked KD）、LfI（competitive/adaptive distillation） |

## 1. 第一类：训练期辅助分支拥有“特权信息”，推理不需要它

### LAL — CVPR 2025

- **文件**：`GRAFT相关/LAL(CVPR 2025).pdf`
- **标题**：LAL: Enhancing 3D Human Motion Prediction with Latency-aware Auxiliary Learning
- **作者**：Xiaoning Sun, Dong Wei, Huaijiang Sun, Shengxiang Hu
- **核心机制**：训练期辅助分支可看到额外的 latency 信息，通过一致性约束逐步融入 primary branch，测试时不增加时间消耗。
- **对 GRAFT 的启发**：`auxiliary sees more → teach primary → auxiliary removed` 的直接范式，对应“local LWGANet stage = primary，global cross-stage teacher = privileged auxiliary”。
- **代码状态**：未找到可确认官方实现，只读论文。

### DiMA — CVPR 2025

- **文件**：`GRAFT相关/DiMA(CVPR2025).pdf`
- **标题**：Distilling Multi-modal Large Language Models for Autonomous Driving
- **作者**：Deepti Hegde 等
- **核心机制**：训练期借助重型 MLLM 世界知识，通过 surrogate tasks / structured representation 增强 vision-based planner，推理时 MLLM 可移除。
- **对 GRAFT 的启发**：强教师不必通过直接 feature MSE 教学生，可以通过多个任务相关 surrogate views 让共享 encoder 内化知识——支持“task path + representation path”双梯度结构。
- **代码状态**：不需要引入 MLLM，只借机制。

### RD-Net — CVPR 2025

- **文件**：`GRAFT相关/RD-Net (CVPR2025).pdf`
- **标题**：Boost the Inference with Co-training: A Depth-guided Mutual Learning Framework for Semi-supervised Medical Polyp Segmentation
- **作者**：Yuxin Li 等
- **核心机制**：训练时 main RGB student + auxiliary depth student 互学习，测试时不需要 depth branch。
- **对 GRAFT 的启发**：直接支持“训练态借一个信息更丰富的辅助学习者，提升最终单一主学生”。
- **代码状态**：官方 `github.com/pingchuan/RD-Net`。

## 2. 第二类：全局 / 多层知识蒸馏给局部表示

### DEO — CVPR 2026 Highlight（本轮最相关）

- **文件**：`GRAFT相关/DEO(CVPR 2026 Highlight).pdf`
- **标题**：Brewing Stronger Features: Dual-Teacher Distillation for Multispectral Earth Observation
- **作者**：Filip Wolf, Blaž Rolih, Luka Čehovin Zajc
- **核心机制**：multispectral teacher + optical VFM teacher 蒸馏学生表示；从 teacher 不同 transformer layers 提取 CLS global + patch-level intermediate features，做 global/patch feature matching。报告 change detection +1.2 pp。
- **对 GRAFT 的启发**：与“遥感 + 表示蒸馏 + change detection downstream”距离最近；不要只蒸馏一个 global vector，应构造 global semantics + stage-level spatial semantics 两类知识。
- **代码状态**：官方 `github.com/wolfilip/DEO-FM`（已下载到 `Model_Reproduction/DEO-FM/`）。

### T-CoRe — CVPR 2025

- **文件**：`GRAFT相关/T-CoRe(CVPR2025).pdf`
- **标题**：When the Future Becomes the Past: Taming Temporal Correspondence for Self-supervised Video Representation Learning
- **作者**：Yang Liu, Qianqian Xu, Peisong Wen, Siran Dai, Qingming Huang
- **核心机制**：auxiliary branch + self-distillation + latent-space representation restoration，让 temporal information 丰富学生表示。
- **对 GRAFT 的启发**：side teacher 不应重建 RGB/pixel，而应在 latent feature space 构造更丰富的 temporal-change representation——支持放弃 RGB reconstruction 作为首版辅助任务。
- **代码状态**：官方 `github.com/yafeng19/T-CORE`（已下载到 `Model_Reproduction/T-CORE/`）。

### ATAS — ICCV 2025

- **文件**：`GRAFT相关/ATAS(ICCV2025).pdf`
- **标题**：ATAS: Any-to-Any Self-Distillation for Enhanced Open-Vocabulary Dense Prediction
- **作者**：Juan Yeo, Soonwoo Cha, Jiwoo Song, Hyunbin Jin, Taesup Kim
- **核心机制**：利用模型自身所有 representation levels 的知识（而非只做 final-layer distillation），同时维持 semantic coherence 与 fine-grained dense detail。
- **对 GRAFT 的启发**：四个 LWGANet stage 都应获得 stage-specific teaching target，而非“global teacher → 统一向量 → 全层硬匹配”。
- **代码状态**：未找到可确认官方实现；第三方 `atas-repro` 自述未达论文收益，不列为权威源码。

### PH-Reg — NeurIPS 2025 Spotlight

- **文件**：`GRAFT相关/PH-Reg(NeurIPS2025Spotlight).pdf`
- **标题**：Vision Transformers with Self-Distilled Registers
- **作者**：Zipeng Yan, Yinjie Chen, Chong Zhou, Bo Dai, Andrew Luo
- **核心机制**：teacher/student 同源初始化，teacher frozen + TTA 得到更干净 dense embedding，student 蒸馏 teacher dense features（cosine + MSE）。
- **对 GRAFT 的启发**：teacher 必须经过一个能产生“更干净/更丰富目标”的处理过程，否则 self-distillation 只是 identity matching——回应“teacher 不能原样回吐 backbone feature”。
- **代码状态**：官方 `github.com/0raiser0/PH-Reg`（已下载到 `Model_Reproduction/PH-Reg/`）。

### COSMOS — CVPR 2025

- **文件**：`GRAFT相关/COSMOS(CVPR2025).pdf`
- **标题**：COSMOS: Cross-Modality Self-Distillation for Vision Language Pre-training
- **作者**：Sanghwan Kim 等
- **核心机制**：global views + local views + cross-attention + self-distillation，提升 contextual understanding 与 dense perception。
- **对 GRAFT 的启发**：支持“global teacher → local stage”的 teacher/student 视野不对称；但本项目不引入文本模态。
- **代码状态**：官方 `github.com/ExplainableML/cosmos`（已下载到 `Model_Reproduction/COSMOS/`）。

## 3. 第三类：不是所有 teacher signal 都值得回传（KGR 依据）

### SDPGO — NeurIPS 2025

- **文件**：`GRAFT相关/SDPGO(NeurIPS2025).pdf`
- **标题**：SDPGO: Efficient Self-Distillation Training Meets Proximal Gradient Optimization
- **作者**：Tongtong Su, Yun Liao, Fengbo Zheng
- **核心机制**：普通 self-KD 往往只复制 common features，未突出 task-critical features；用 gradient information 动态衡量哪些 feature knowledge 更 task-critical，再动态调整蒸馏。
- **对 GRAFT 的启发**：与“外挂强不强 = 它制造的梯度有没有信息”直接同构；GRAFT 不应所有像素×所有通道×所有 stage 统一 MSE，而应有 gradient relevance / knowledge-gap selection。
- **代码状态**：官方 repo 当前为空（`nanxiaotong/SDGPO`），只读论文。

### ADMD — ISPRS Journal 2025

- **文件**：`GRAFT相关/ADMD(ISPRSJournal2025).pdf`
- **标题**：Adaptive Discrepancy Masked Distillation for Remote Sensing Object Detection
- **作者**：（ISPRS Journal of Photogrammetry and Remote Sensing, Vol. 222, pp. 54–63）
- **核心机制**：teacher/student 每个位置都做 KD 并不合理（有些像素甚至有害）；用 teacher-student feature discrepancy 定位应优先蒸馏的位置。
- **对 GRAFT 的启发**：KGR 最直接的遥感依据之一——teacher 可靠且 student 明显缺失 → 强教学；teacher 不确定或 student 已学会 → 降低教学。
- **代码状态**：未核验到明确官方 repo，只读论文。DOI: `10.1016/j.isprsjprs.2025.02.006`。

### LfI — CVPR 2026

- **文件**：`GRAFT相关/LfI(CVPR2026).pdf`
- **标题**：Learning from Itself: Mining Internal Knowledge from Vision Language Models for Continual Learning
- **作者**：Yizheng Gong, Siyue Yu, Waleed Al-Nuaimy, Jimin Xiao
- **核心机制**：temporary vision classifier + CLIP branch + adaptive mutual distillation，更强一侧教更弱一侧；competitive distillation 基于两侧即时 loss 关系计算动态 transfer weight。
- **对 GRAFT 的启发**：teacher 不应被假设为每时每刻都比 local probe 强；可用 teacher confidence + teacher/student gap 决定“这次是否应该教”。
- **代码状态**：官方 `github.com/jordangong/continual-learning`（已下载到 `Model_Reproduction/LfI/`）。
